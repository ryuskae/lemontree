# 레몬트리 기타 교재

학원 기타 교재를 태블릿과 휴대폰에서 보는 웹앱입니다. 교재 PDF는 구글 드라이브(GoodNotes 자동 백업 폴더)에서 읽고, 학생 진도와 연습 기록은 Firebase에 저장합니다.

- 주소: https://ryuskae.github.io/lemontree/textbook/
- `js/config.js`의 `firebase` 값이 비어 있으면 **체험 모드**로 열립니다. 체험 모드는 견본 교재와 시험용 학생(민준 0315, 서연 1102)으로 모든 화면을 미리 써 볼 수 있고, 데이터는 그 기기에만 저장됩니다.

## 처음 한 번 하는 설정

아이패드 사파리로도 모두 할 수 있습니다. 순서대로 진행해 주세요.

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 선생님 구글 계정으로 들어갑니다.
2. '프로젝트 추가' → 이름은 `lemontree-textbook` 정도로 정합니다. 구글 애널리틱스는 꺼도 됩니다.
3. 무료 요금제(Spark)로 충분합니다.

### 2. 웹 앱 등록하고 설정값 받기
1. 프로젝트 개요 화면에서 `</>`(웹) 아이콘을 누릅니다.
2. 앱 이름에 `textbook`을 쓰고 '앱 등록'을 누릅니다. Firebase 호스팅은 체크하지 않습니다.
3. 화면에 나오는 `firebaseConfig = { apiKey: ..., ... }` 부분을 복사해 둡니다. 이 값을 Claude에게 보내면 `js/config.js`에 넣어 드립니다.

### 3. 로그인 방식 켜기
1. 왼쪽 메뉴 '빌드 › Authentication' → '시작하기'.
2. 'Sign-in method' 탭에서 **이메일/비밀번호**를 사용 설정합니다. (학생과 학원 태블릿이 이 방식을 씁니다. 실제 메일은 가지 않습니다.)
3. 같은 탭에서 **Google**을 사용 설정합니다. (선생님 관리자 로그인용)
4. 'Settings' 탭 › '승인된 도메인'에 `ryuskae.github.io`를 추가합니다.

### 4. 데이터베이스 만들고 보안 규칙 넣기
1. 왼쪽 메뉴 '빌드 › Firestore Database' → '데이터베이스 만들기'.
2. 위치는 `asia-northeast3 (서울)`, 모드는 '프로덕션 모드'로 만듭니다.
3. '규칙' 탭을 열고, 이 폴더의 `firestore.rules` 내용을 통째로 붙여 넣습니다. `ADMIN_EMAIL`을 선생님 구글 계정 주소로 바꾼 뒤 '게시'를 누릅니다.

### 5. 구글 드라이브 읽기 허용
1. https://console.cloud.google.com 에서 화면 위쪽 프로젝트 선택을 방금 만든 Firebase 프로젝트로 바꿉니다.
2. 'API 및 서비스 › 라이브러리'에서 **Google Drive API**를 검색해 '사용'을 누릅니다.
3. 'API 및 서비스 › 사용자 인증 정보'에서 `Browser key (auto created by Firebase)`를 엽니다.
   - 'API 제한사항'이 '키 제한'으로 되어 있으면 목록에 **Google Drive API**를 추가로 체크합니다.
   - '애플리케이션 제한사항'은 '웹사이트'를 고르고 `https://ryuskae.github.io/*`와 `https://<프로젝트ID>.firebaseapp.com/*` 두 줄을 넣습니다. 두 번째 주소가 빠지면 선생님 구글 로그인이 막힙니다.
4. 저장합니다.

### 6. 교재 폴더 공유
1. 구글 드라이브에서 `GoodNotes › 음악교재` 폴더를 길게 눌러 '공유' → '일반 액세스'를 **링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
2. 폴더 안 파일은 모두 같은 설정을 따릅니다. GoodNotes가 자동 백업으로 파일을 갱신해도 링크는 그대로 유지됩니다.
3. 파일 주소를 아는 사람은 열어볼 수 있게 되지만, 앱은 로그인한 학생에게만 배정된 교재의 주소를 알려줍니다.

### 7. 앱에서 마무리
1. 앱 주소를 열고 '선생님 로그인'으로 들어갑니다.
2. **설정** 탭에서 학원 태블릿 비밀번호를 만듭니다.
3. **교재** 탭에서 카테고리(예: 일렉기타, 통기타, 테크닉편)를 만들고, 드라이브 파일 링크를 붙여 넣어 교재를 추가합니다. 카테고리 안의 교재는 위에서부터 기초 순서이며 화살표로 순서를 바꿉니다.
4. 교재마다 목차(곡 이름 + 시작 쪽)를 입력합니다. 앱은 이 목차로 어느 쪽이 어느 곡인지 압니다. 예를 들어 9쪽에서 시작하는 4쪽짜리 곡의 11쪽은 "곡 이름 · 3/4쪽"으로 표시됩니다.
5. **학생** 탭에서 학생(이름 + 생일 4자리)을 추가하면서 카테고리마다 지금 교재, 곡, 곡 안의 쪽을 고릅니다. 학생에게는 카테고리마다 지금 교재와 그보다 앞선 교재만 보입니다.
6. 학원 태블릿에서 앱을 열어 '학원 태블릿으로 등록'을 누르고 비밀번호를 입력합니다.

## 학원 레노버 태블릿 설정
1. 크롬으로 앱 주소를 열고 메뉴(⋮) › '앱 설치'(또는 '홈 화면에 추가')를 누릅니다.
2. 설정 › 보안 및 개인정보 보호 › 기타 보안 설정 › **앱 고정**을 켭니다. (메뉴 이름은 기종마다 조금 다릅니다.)
3. 설치된 앱을 연 뒤 최근 앱 화면에서 앱 아이콘을 누르고 '고정'을 고르면 이 앱만 쓸 수 있습니다. 해제는 뒤로 가기와 최근 앱 버튼을 함께 길게 누릅니다.

## GoodNotes 자동 백업
- 아이패드에서는 백업이 기본적으로 약 12시간 간격으로 돌아갑니다. GoodNotes 설정 › 클라우드 및 백업에서 **자동 백업 빈도 늘리기**를 켜면 1~2분 간격이 되고, 급할 때는 '지금 백업'을 누르면 됩니다.
- 자동 백업 PDF에는 GoodNotes 개요(목차)가 들어가지 않아서, 목차는 앱의 교재 화면에서 입력합니다.
- 교재에 쓴 필기도 백업 PDF에 함께 들어가 학생에게 보입니다.

## 교재를 고쳤을 때 진도
학생 진도는 쪽 번호와 함께 목차 항목 이름으로 저장됩니다.
- 쪽수가 바뀌지 않았으면 그대로 그 쪽을 엽니다.
- 쪽수가 바뀌면 관리자 교재 목록에 '목차 확인 필요'가 뜹니다. 목차의 쪽 번호를 고쳐 저장하면 학생 진도가 새 쪽으로 옮겨집니다.
- 고치기 전까지 학생에게는 "진도 위치가 달라졌을 수 있어요"라는 안내와 함께 지난 진도가 글로 보이고, 자동으로 이동하지 않습니다.
- 목차에서 사라진 항목에 진도가 있던 학생은 지난 진도가 글로만 보입니다.

## 학생 화면
- 교재 보기에서 한 쪽·두 쪽을 고를 수 있고, 고른 방식은 그 기기에 기억됩니다.
- 전체보기를 누르면 악보만 화면에 가득 찹니다. 화면 가운데를 두 번 누르면 원래 화면으로 돌아옵니다.
- 좋아요를 누르면 곡 선호가 기록되고, 관리자 **기록** 탭에서 곡별 좋아요 수를 볼 수 있습니다. 두 쪽에 곡이 둘이면 어느 곡인지 묻습니다.

## 파일 구성
- `index.html`, `app.css` – 화면
- `js/main.js` – 로그인, 학생 홈, 학원 태블릿, 관리자 화면
- `js/reader.js` – 교재 보기 (한 쪽·두 쪽, 전체보기, 목차, 진도 저장, 좋아요, 연습 시간 기록)
- `js/pdfsource.js` – 드라이브에서 PDF를 받아 기기에 저장
- `js/store-firebase.js` / `js/store-demo.js` – 실제 모드 / 체험 모드 저장소
- `js/core.js` – 진도 계산 규칙
- `firestore.rules` – 보안 규칙 (Firebase 콘솔에 붙여 넣는 원본)
- `vendor/pdfjs` – PDF 표시 엔진 (Mozilla pdf.js 3.11, Apache 2.0)
